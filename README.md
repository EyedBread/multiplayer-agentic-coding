# Multiplayer Agentic Coding

A multiplayer coding room where everyone can see the agents work, make decisions together, and build as a team.

## The idea

One person hosts a session for a Git project, and teammates join a shared workspace. Each teammate works with a coding agent while the whole team can follow every session in a live split-screen view.

When an agent needs an opinion or a decision, the question becomes a team vote. Shared visibility helps teammates track progress, spot overlapping work, and stay aligned as the project evolves.

## Core experience

- **Host and join:** Start a project session and invite teammates into the same room.
- **Live agent sessions:** See what each teammate and their agent are working on in real time.
- **Team decisions:** Surface agent questions with context and let teammates vote on the direction.
- **Shared awareness:** Track progress, dependencies, and potential divergence across sessions.
- **Collective momentum:** Make building together engaging, fun, useful, and efficient.
